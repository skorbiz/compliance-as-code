## Malicious or accidental USB insertion on edge device


### At a glance

- **Edge / Cloud:** Edge
- **Conduit / exposure area:** USB / physical ports
- **Phase:** All
- **Category (IEC 62443-3-3 FR):** System Integrity
- **IEC 62443-3-3 requirement inspiration:** —
- **Risk treatment:** Accept (0 planned actions)

### Risk scenario

1. **Vulnerability** — Edge device USB and physical ports are physically accessible
2. **Event / threat** — Either a malicious actor with physical access to the edge device (deliberate, moderate skill), or a non-malicious developer during maintenance (trusted insider, unaware the media is infected), inserts a USB device carrying malware into an exposed port
3. **Consequence** — Ability to execute code on the edge, taking down the whole platform and potentially connected machines

### Controls

#### Existing controls

- balenaOS is a minimal Linux distribution with no autorun/autoplay for removable media, so an inserted USB drive is not automatically mounted or executed; running anything from it requires a manual action on the device


:::note
Autorun behavior is based on standard balenaOS/Linux defaults
