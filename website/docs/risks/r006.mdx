## Non-rotated credentials reused by a former employee or malicious software


### At a glance

- **Edge / Cloud:** Both
- **Conduit / exposure area:** Access keys / credentials
- **Phase:** All
- **Category (IEC 62443-3-3 FR):** Identification and Authentication Control
- **IEC 62443-3-3 requirement inspiration:** —
- **Risk treatment:** Accept (0 planned actions)

### Risk scenario

1. **Vulnerability** — Access keys and credentials are not rotated when staff leave, so old credentials remain valid
2. **Event / threat** — A former employee (insider knowledge, retains valid non-rotated credentials, high motivation), or malicious software (e.g. a credential-scanning bot or malware that discovers an old leaked key), reuses non-rotated credentials to access and damage the system
3. **Consequence** — Full system access
