## Sudden power loss corrupts edge device disk


### At a glance

- **Edge / Cloud:** Edge
- **Conduit / exposure area:** Edge device disk
- **Phase:** All
- **Category (IEC 62443-3-3 FR):** Resource Availability, System Integrity
- **IEC 62443-3-3 requirement inspiration:** —
- **Risk treatment:** Accept (0 planned actions)

### Risk scenario

1. **Vulnerability** — A sudden loss of power can corrupt in-flight writes on the edge device disk
2. **Event / threat** — An environmental or accidental event (power outage, no deliberate actor) cuts power to the edge device while data is being written, corrupting the disk
3. **Consequence** — Buffered data is lost or the disk is corrupted until the device is restored
