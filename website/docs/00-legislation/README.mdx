This folder is a working index of legislation. I keep notes on as part of this proof of concept.
Some entries track legislation I am actively applying to a real project; others are kept purely for reference because they relate to the same space.
Each page should turn a source text into traceable input for requirements, operating procedures, risk assessments, or compliance evidence.

The goal is not to reproduce a law text. Keep notes short and ALWAYS record the specific article, section, or official source that supports the note.

## How to maintain these notes

For each entry, capture only what's useful to understand the legislation's relevance:

1. Identify the official source and the exact article, clause, or section.
2. Explain the implication in plain language.
3. Link to the downstream requirement, process, risk, or evidence page when one exists.
4. Record open questions and the current understanding status.
