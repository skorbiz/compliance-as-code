The [IEC 62443-3-2:2020 notes](./03-iec-62443-3-2-2020.mdx) contain notes and requirements about risk assessments.
The [IEC 62443-3-3:2019 notes](./04-iec-62443-3-3-2019.mdx) contain requirements a product must meet about cyber security implementation.

## IEC 62443-1-1 — Terminology, concepts and models

| Aspect   | Summary                                                                                              |
| -------- | ---------------------------------------------------------------------------------------------------- |
| **What** | Defines the terminology, concepts, and reference models (zones, conduits, levels) for IACS security. |

## IEC 62443-3-2 — Security risk assessment for system design

| Aspect    | Summary                                                                                                                                                              |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **What**  | Provides guidelines for conducting security risk assessments                                                                                                         |
| **Notes** | Complements the requirements in IEC 62443-3-3. Good explanation of general risk assessment columns like likelihood, impact, threat and vulnerability identifications |

## IEC 62443-3-3 — System security requirements and security levels

| Aspect    | Summary                                                                                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **What**  | System-level security requirements grouped by security level, including authentication and authorisation.                                                                       |
| **Notes** | The 62443-3 parts are relatively concise on authentication and authorisation. See the [IEC 62443-3-3:2019 notes](./04-iec-62443-3-3-2019.mdx) for a full requirement breakdown. |

## IEC 62443-4-1 — Secure product development lifecycle

| Aspect           | Summary                                                                                                                                 |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **What**         | Requirements for a secure product development lifecycle for IACS components.                                                            |
| **CRA relation** | Directly supports the CRA lifecycle and secure-by-design obligations.                                                                   |
| **Notes**        | IEC 62443-4-1 specifies a secure development lifecycle for IACS components;                                                             |

## IEC 62443-4-2 — Technical security requirements for components

| Aspect   | Summary                                                                     |
| -------- | --------------------------------------------------------------------------- |
| **What** | Component-level technical security requirements aligned to security levels. |
